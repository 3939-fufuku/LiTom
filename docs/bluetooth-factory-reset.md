# LiTom Bluetooth完全リセット手順

Bluetoothの再ペアリングができない、`settings_reset.uf2`を書き込んでも以前の接続情報が残る場合に使用する手順です。

この手順では、右手centralに保存されたPC・スマートフォンとの結合情報と、左右間のsplit結合情報を削除します。左右両方に専用ファームを書き込んでください。

## 必要なファーム

GitHub Actionsの成果物から、次の2つをダウンロードします。

- `LiTom_R-bluetooth-reset`: 右手用Bluetoothリセットファーム
- `LiTom_L-bluetooth-reset`: 左手用Bluetoothリセットファーム

リセット後に書き戻す通常ファームも用意してください。

- `LiTom_R`: 右手用通常ファーム
- `LiTom_L`: 左手用通常ファーム

## リセット手順

1. PC・スマートフォンのBluetooth設定から、登録済みのLiTomを削除します。
2. LiTomの左右両方の電源を切ります。
3. 右手XIAOをブートローダーモードにし、右手用`LiTom_R-bluetooth-reset.uf2`を書き込みます。
4. 右手を5秒以上起動したままにします。
5. 左手XIAOをブートローダーモードにし、左手用`LiTom_L-bluetooth-reset.uf2`を書き込みます。
6. 左手を5秒以上起動したままにします。
7. 左右両方の電源を切ります。
8. 右手に通常の`LiTom_R.uf2`、左手に通常の`LiTom_L.uf2`を書き戻します。
9. 右手、左手の順に電源を入れ、左右が接続されるまで待ちます。
10. PC・スマートフォンからLiTomを新しいキーボードとしてペアリングします。

## 重要

Bluetoothリセットファームは起動するたびに結合情報を削除します。動作確認後は必ず通常ファームへ書き戻してください。リセットファームのままではペアリング情報を保持できません。

このファームはBluetooth結合情報の復旧専用です。DYAStudioのキーマップや入力プロセッサ設定まで初期化したい場合は、別途`settings_reset.uf2`を使用してください。
